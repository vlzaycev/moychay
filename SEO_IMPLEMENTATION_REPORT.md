Дата: 15.10.2026. Изменения закоммичены локально и **не опубликованы**: на сайт они попадут только после Push в GitHub Desktop.
Точка отката: тег `pre-seo-pages`.

Этот файл и `TELEGRAM_INTEGRATION_TODO.md` исключены из публикации в `_config.yml`.

## 1. Архитектура

- Сайт остался статическим: GitHub Pages за Cloudflare, сборка через `python3 _build/build.py`.
- Общий шаблон `_build/template.html` содержит head, header, footer и JS. Главная собирается из `_build/pages/home.html`, внутренние страницы – из `_build/pages.py`: там тексты EN/RU, SEO и вёрстка блоков.
- Header не изменился. На внутренних страницах его пункты ведут к разделам главной (`/#prices` и т.д.). Новых пунктов в верхнем меню нет.
- Переключатель языка ведёт на ту же страницу второй версии: `/matcha/` ↔ `/ru/matcha/`.
- Альтернативных URL (`/tea-ceremonies/` и т.п.) раньше не было, поэтому редиректы не нужны. URL без слеша (`/tea`) GitHub Pages сам перенаправляет на `/tea/` (301).

## 6. Формы

- **Контактная** (`/contact/`, `/ru/contact/`):
  - поля: имя*, email*, WhatsApp (EN) или Telegram username (RU) – необязательное, сообщение*;
  - кнопка «Send message» / «Отправить сообщение».
- **B2B** (`/wholesale/`, `/ru/wholesale/`): те же поля плюс «Company / Business name» / «Название компании»*. Тип обращения – `inquiry_type: wholesale`.
- **Клиентская часть:**
  - подписи и отметки обязательных полей;
  - ошибки у каждого поля (`aria-invalid` и `aria-describedby`);
  - проверка email, WhatsApp в международном формате, Telegram username без обязательного `@`;
  - `inputmode="tel"` для телефона;
  - состояние загрузки;
  - honeypot-поле и замер времени заполнения;
  - работа с клавиатуры.
- **Сообщение об успехе** показывается только после ответа сервера `{ok:true}`.
- **Аналитика:** события `contact_form_submit` / `wholesale_form_submit` отправляются только после подтверждения сервером. Передаются только место и язык, без имени, email, телефона, username и текста.
- **Текущий статус: формы отключены.** Сервер ещё не развёрнут, поэтому `cfg_form_endpoint = ""`. Поля неактивны, сверху честная пометка «форма скоро заработает» и ссылка на WhatsApp/Telegram. Ничего никуда не отправляется.
- **Политика конфиденциальности отсутствует.** Под формой есть короткий текст о том, что контакты используются только для ответа, но ссылки на политику нет: фиктивный документ не размещён. Политику нужно подготовить, особенно с учётом Google Signals и рекламных cookies.

## 8. Technical SEO – результаты проверок

- **Каждая страница:**
  - уникальный Title и description;
  - один H1;
  - self-canonical;
  - hreflang en/ru/x-default с взаимными ссылками;
  - Open Graph;
  - alt у всех изображений;
  - `noindex` нет.
- **HTTP-статусы:** локальный сервер, эмулирующий GitHub Pages: 14 страниц отдают 200, неизвестные URL (`/nope`, `/ru/nope`) – 404 с кастомной страницей 404 (EN/RU), без soft 404.
- **Sitemap:** `sitemap.xml` – 14 URL с hreflang-альтернативами, без 404 и редиректов. `robots.txt` ничего не блокирует.
- **Structured data:**
  - главная: LocalBusiness (`CafeOrCoffeeShop` и `Store`) и WebSite с alternateName «Мойчай Пхукет»;
  - contact: LocalBusiness и BreadcrumbList;
  - остальные страницы: BreadcrumbList;
  - events: Event из таблицы.
  - Рейтингов, отзывов и наград нет.
  - Микроразметка не гарантирует расширенные результаты.
- **NAP:** Moychay Phuket, 2nd floor, Boat Avenue, Bang Tao, Choeng Thale, Phuket 83110, ежедневно 11:00–22:00, +66 81 795 9110. Данные одинаковы на всех страницах и в разметке.
  - Перед продвижением стоит сверить с Google Business Profile.

## 10. SEO-разграничение с phuket.moychay.asia (рекомендации)

Магазин не трогали: canonical, индексация и код без изменений. Предложения, что можно сделать там:

1. **Title главной магазина** – добавить «Online Shop / Интернет-магазин»: «Moychay Phuket Online Shop – Chinese Tea Delivery in Thailand». Так Google не будет показывать его как сайт чайной.
2. **Ссылка «Tea house in Bangtao → teaphuket.com»** в шапке или футере магазина. Обратная ссылка уже стоит в шапке и футере teaphuket.com.
3. **Микроразметка магазина:** тип `OnlineStore` / `Organization` без адреса чайной и часов работы. Если LocalBusiness с адресом нужен, его `url` должен указывать на teaphuket.com.
4. **Google Business Profile:** поле «Сайт» → `https://teaphuket.com/`, отдельная ссылка «Заказать онлайн» → магазин.
5. **Страница «О нас» / «Контакты» магазина** – ссылка на teaphuket.com как на сайт физической чайной.
6. **Внешние упоминания** (Instagram bio, Facebook, TripAdvisor, каталоги, Telegram) → teaphuket.com как основной сайт чайной.
